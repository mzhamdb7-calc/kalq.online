Pregnancy due date formula

The standard estimate adds 280 days to the first day of the last menstrual period. The optional adjustment shifts the estimate according to cycle length.

Standard
Estimated due date = LMP + 280 days
Adjusted
Estimated due date = LMP + 280 + (cycle length − 28) days
Pregnancy age
Today − cycle-adjusted pregnancy start
Worked example: A 30-day average cycle adds 2 days to the standard estimate. A 26-day average cycle subtracts 2 days.

Clinical priority: When a healthcare professional provides or revises an official estimated due date, use that clinical date instead of repeatedly recalculating from menstrual information.

Tips and common mistakes

Correct date entry is more useful than adding extra questions. These checks keep the result focused and reduce misleading precision.

Practical tips

  • Use the first day your last period began.
  • Enter your usual average cycle length, not one unusual cycle.
  • Read pregnancy age in weeks and days rather than approximate months.
  • Save the date on which the report was generated.
  • Record a clinician-confirmed due date separately.
  • Keep pregnancy dates private when using shared devices.

Common mistakes

  • Entering the final day of the period.
  • Entering period duration as cycle length.
  • Using an uncertain date without acknowledging the uncertainty.
  • Confusing gestational age with time since conception.
  • Treating the due date as an exact delivery date.
  • Continuing to use the estimate after a clinician revises it.
  • Using this calculator for IVF treatment dates.

Method, guidance, and references

Calculation Guide

How to use the calculator, formulas, assumptions, tips, common mistakes, FAQs, references, and limitations.

How to use

  1. Select the first day the last period began.
  2. Keep 28 days or adjust to the usual average cycle length.
  3. Calculate and review the due date, pregnancy age, and timeline.
  4. Save this report for personal reference or professional discussion.

Formula

EDD = LMP + 280 days
Adjusted EDD = LMP + 280 + (cycle − 28) days

A 30-day cycle adds two days; a 26-day cycle subtracts two days.

Assumptions

  • The entered date is the first day of the last menstrual period.
  • The cycle length represents the usual average.
  • No clinician-confirmed date has replaced this estimate.
  • The calculation is not based on IVF treatment dates.

Practical tips

  • Use weeks and days instead of approximate months.
  • Save the report-generation date.
  • Record an official revised due date separately.
  • Keep menstrual and pregnancy dates private.

Common mistakes

  • Entering the final day of the period.
  • Entering period duration as cycle length.
  • Using an unusual cycle instead of the normal average.
  • Confusing gestational age with time since conception.
  • Treating the due date as exact.
  • Using this method after a clinical revision.
