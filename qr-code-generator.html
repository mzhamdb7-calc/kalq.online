Printing guidance

  • Keep the clear margin around all four sides.
  • Use a dark foreground and light background.
  • Avoid glossy surfaces, folds and strong reflections.
  • Do not stretch or crop the QR image.
  • Test from the expected scanning distance before mass printing.

Privacy and security

Static QR codes are generated locally in your browser. Do not include confidential information in a QR code intended for public display. Wi-Fi passwords are masked in the page summary and report.

What is a QR code?

A QR code is a two-dimensional barcode that can store a website address, text, contact information, Wi-Fi details and other data.

Is this QR Code Generator free?

Yes. Standard static QR codes can be created and downloaded without registration.

Do static QR codes expire?

The image does not expire, but a linked page may stop working if its address changes or it is removed.

What is static versus dynamic?

A static code stores the final content directly. A dynamic code uses a managed redirect that may support editable destinations and analytics.

Which error-correction level should I use?

Medium is suitable for normal use. High is recommended when a logo is added or minor dirt or damage is expected.

Can I add a logo?

Yes. Keep it modest, maintain strong contrast and test the result. High error correction is selected automatically.

Why will my QR code not scan?

Common causes include low contrast, excessive data, a missing margin, a large logo, poor print quality, glare or a code printed too small.

Is PNG, SVG or PDF better?

PNG suits digital use, SVG suits scalable printing, and PDF provides a complete printable validation report.

Can I create a Wi-Fi QR code?

Yes. Enter the network name, password and security type. Anyone with the code may receive the network details.

Is my information stored?

This page is designed to create the QR code locally. Review the deployed website privacy policy before using sensitive information.

Can I edit a downloaded QR code?

The content of a static QR code cannot be changed. Generate a new code when the information changes.

Can I create a DuitNow QR here?

No official merchant credentials are issued here. Malaysian businesses should obtain DuitNow QR from a participating provider.

Can I use it commercially?

General static QR codes may be used on menus, cards, packaging and signs. You remain responsible for the content and logos.

How should I print my QR code?

Preserve the margin, avoid distortion, use a high-quality file and test the final sample from the expected scanning distance.
