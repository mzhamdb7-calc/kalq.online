Calculation Method

Total calendar days = end date − start date. When “Include end date” is enabled, one day is added. Calendar years, months and days are counted using real month lengths rather than assuming 30-day months.

  • Complete weeks = floor(total days ÷ 7).
  • Remaining days = total days mod 7.
  • Working days = total days − weekends − non-weekend holidays − custom exclusions.
  • Exact elapsed time converts the selected start and end time zones to UTC. Inclusive date counting affects calendar-day results, not timestamp duration.

Useful Tips

  • Enable inclusive counting when both boundary dates should count.
  • Choose the correct weekend rule before using the working-day result.
  • For Malaysia, select a state or federal territory so subdivision holidays can be filtered when supplied by the live source.
  • Add company shutdowns or personal leave under custom exclusions.
  • Use signed mode to show whether the second date occurs before the first.

Frequently Asked Questions

Does the calculator include the end date?

The end date is excluded by default. Enable “Include end date” when both start and end dates should count.

Why does one month not always equal 30 days?

Calendar months contain 28, 29, 30 or 31 days. Calendar duration uses the actual month boundaries.

How are leap years handled?

The calculator automatically counts 29 February whenever it falls inside the selected range.

How are Malaysian working days calculated?

Select Malaysia, choose a state or territory, select the weekend rule, and enable public-holiday exclusion. Malaysia requires a selected state or federal territory. The calculator then requests that state’s published holiday records from the Malaysia-specific provider.

Are holidays on weekends counted twice?

No. A holiday that falls on an excluded weekend is shown as an overlap but is not subtracted again.

Can I compare dates in different directions?

Yes. Absolute mode always shows a positive duration. Signed mode shows a negative result when the end date is earlier.

How does exact time work?

Enable time inputs and select a shared time zone, or enable a different end time zone for international events. The calculator converts both timestamps to UTC. Inclusive calendar counting does not add 24 hours to this exact duration.

Are my dates stored?

No server storage is used by this page. Shareable text is only created when you choose a share or copy action.
